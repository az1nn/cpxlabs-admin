# cpxlabs-admin

Enterprise React starter for dashboards, CRM, ERP, backoffice and administrative applications.

## Architectural baseline

- React + Vite
- TypeScript (strict)
- TanStack Router
- TanStack Query
- TanStack Table
- React Hook Form + Zod
- Tailwind CSS + shadcn/ui + Base UI
- Typed capabilities for authorization
- Resource Registry and provider/adapters architecture
- Backend-agnostic frontend
- Optional reference API (Fastify + PostgreSQL)
- Vitest + Testing Library + Playwright + Storybook
- OpenTelemetry and OpenFeature abstractions

The project is being bootstrapped from an architecture-first specification. Detailed ADRs and implementation specifications live under `docs/`.
